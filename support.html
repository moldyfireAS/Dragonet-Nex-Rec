Common Issues

The launcher will not open

Try these checks in order:

  1. Restart the computer.
  2. Confirm you downloaded the current official release.
  3. Check whether Windows blocked or quarantined the file.
  4. Make sure required runtime components are installed.
  5. Capture any error message before asking for support.
The launcher cannot connect

Check the N3XI0M status page first. If services are operational, confirm your internet connection works normally and that a firewall, VPN, proxy, DNS filter, or security product is not blocking the launcher.

The download failed or disappeared

Download only from the official N3XI0M distribution source. Check your browser download history and antivirus quarantine before downloading again.

I have an old version

Check the download page for the current release. Avoid mixing files from different builds unless the release instructions specifically tell you to do so.

Discord or member counts are unavailable

Discord statistics can occasionally enter a degraded state even when the main website is operational. Check the status page for the latest service information.

Before Asking for Help

Providing useful diagnostic information makes support much faster. Do not post passwords, account tokens, authentication cookies, private keys, or other secrets.

System

  • Windows version
  • 64-bit architecture confirmation
  • Launcher version
  • Installation location

Problem

  • What you expected to happen
  • What actually happened
  • Exact error text
  • Steps that reproduce the issue

Evidence

  • Relevant screenshots
  • Launcher logs
  • Approximate time the failure occurred
  • Any troubleshooting already attempted
